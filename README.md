# 门诊处方数据报送台

导入门诊处方（处方号 / 患者编号 / 药品 / 数量 / 费用），**分批提交**到监管接口，
监管结果**逐行回写**；用户可以**只重送失败行**，系统从机制上保证不会整批重复报送。

零第三方依赖，仅需 Python 3.8+（标准库 `http.server` / `sqlite3` / `urllib` / `csv`）。

## 快速开始

```bash
python3 run.py
# [监管端模拟器] http://127.0.0.1:8001/v1/prescriptions
# [门诊处方报送台] http://127.0.0.1:8000/
```

浏览器打开 <http://127.0.0.1:8000/>：

1. **导入**：选择 CSV（可点"下载示例 CSV"），系统先做本地校验；
2. **提交待报送行**：只发送 `待报送(pending)` 行，按 `CHUNK_SIZE`（默认 20 行/片）分批发往监管接口；
3. 监管返回结果**回写到每一行**（受理号 / 错误码 / 错误说明 / 尝试次数 / 时间戳）；
4. **仅重送失败行**：只发送 `报送失败(failed)` 行；已受理、本地无效、待报送行一律不重发；
5. **导出报送结果 CSV**：原始列 + 状态/错误/受理号/尝试次数/时间。

配置可用环境变量覆盖：`APP_PORT` `MOCK_PORT` `REGULATOR_URL` `ORG_CODE`
`CHUNK_SIZE` `DB_PATH` `MOCK_DB_PATH`（见 `app/config.py`）。

## CSV 格式

表头支持中英文别名，列顺序不强制：

| 处方号 | 患者编号 | 药品 | 数量 | 费用 |
|---|---|---|---|---|
| RX20260926001 | P10001 | 阿莫西林胶囊 | 3 | 45.60 |

- 编码自动识别 UTF-8（含 BOM）/ GBK；
- **本地校验失败的行**（必填为空、数量非正整数、费用非数字、文件内处方号重复）
  标记为 `本地无效`，**永不发送**，错误原因逐行回写；
- 数值业务上限（数量>500、费用>10000 等）由监管端判定并逐行回写错误。

## 防重复报送是怎么保证的

| 层次 | 机制 |
|---|---|
| 行级状态机 | 每行独立状态：`pending / success / failed / invalid`。提交只取 pending，重送只取 failed；`success`、`invalid` 在任何接口都不会被再次发送 |
| 批次并发锁 | 同一批次提交/重送期间，第二次请求直接返回 **HTTP 409 `blocked`**，0 行发送，并写审计日志 |
| 批次状态锁 | 报送中批次标记 `processing`；进程崩溃遗留的 processing 状态在启动时按行状态自动恢复 |
| 监管端幂等 | 监管接口以**处方号**为幂等键；已受理处方号再次提交返回 `4091 禁止重复报送`，该行回写失败而不是重复入账 |
| 片级失败隔离 | 某个分片网络失败 / HTTP 5xx，仅该片行标记 `failed(E_RETRY)`，其它片照常受理；重送时只补这些行 |
| 全量审计 | 导入 / 提交 / 重送 / 每行成功失败 / 并发拦截均留痕（批次详情页可查看） |

## 监管端模拟器规则（确定性，便于演示）

- 处方号已受理 → `4091` 禁止重复报送（永久失败）
- 数量 > 500 → `4001`（永久）；费用 > 10000 → `4002`（永久）
- 必填缺失 / 数量非正整数 → `4000`（永久）
- 处方号以 `7` 结尾 → `5001` 瞬时失败（**同一处方号仅第一次失败，重送即恢复**，模拟真实抖动）
- 请求带 `X-Mock-Flaky` → 本批所有行瞬时失败；`X-Mock-Outage` → 首次整批 HTTP 503（之后恢复）
- 页面上的两个勾选框用于演示上述瞬时故障；"重置监管端模拟器"清空受理记录

> 接真实监管平台时，在 `REGULATOR_URL` 指向真实地址即可；请求/响应契约见
> `app/regulator_client.py` 顶部注释（结果按处方号逐行对应）。

## HTTP API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/batches` | 上传 CSV（body 为文件原始字节，`X-Filename` 传文件名） |
| GET | `/api/batches` | 批次列表（含各状态行数） |
| GET | `/api/batches/{id}` | 批次明细（逐行状态与回写结果） |
| POST | `/api/batches/{id}/submit` | 提交待报送行，body：`{"chunk_size":20}` |
| POST | `/api/batches/{id}/retry` | **仅重送失败行** |
| GET | `/api/batches/{id}/failed` | 失败行清单 |
| GET | `/api/batches/{id}/export.csv` | 导出报送结果 |
| GET | `/api/batches/{id}/audit` | 审计日志 |
| POST | `/api/mock/reset` | 重置模拟器（演示用） |

## 目录结构

```
run.py                     一键启动（平台 + 监管模拟器）
app/
  config.py                环境变量配置
  db.py                    SQLite 表结构 / 连接 / 审计
  importer.py              CSV 解析 + 本地校验 + 入库
  regulator_client.py      监管接口客户端（urllib，含传输错误分类）
  reporter.py              报送引擎：分批、逐行回写、只重送失败、并发锁
  mock_regulator.py        监管接口模拟器（幂等 + 确定性规则）
  webapp.py                REST API + 静态文件服务
  static/index.html        单页前端
tests/                     unittest（引擎单测 + 双服务端到端测试）
```
